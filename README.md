# 幕稿 · 视频脚本编辑器

幕稿是一款本地优先的中文音画脚本编辑器。把口播文案、画面、BGM / 音效和附注放在同一份稿件中，整理好后导出给剪辑、审稿或打印使用。

## 主要功能

- **音画对照写作**：文案与制作说明并排编辑，输入框随内容增高；支持多份脚本、标题、简介和段落大纲。
- **整段整理**：上方 / 下方插入、复制、删除、光标分段、合并和“移动至…”。拖动正文或大纲中的六点柄时，文案、制作说明和配图一起移动。
- **字数与口播估时**：查看全文和逐段统计，调整中英文语速、额外停顿，也可直接指定单段时长。
- **保存与撤销**：浏览器自动保存，支持撤销、重做和历史版本；保存失败或其他标签页出现版本冲突时会提醒。
- **段落配图**：每段可放一张图片，支持上传、替换、放大预览、移除和撤销；无配图时隐藏图片栏。
- **可选 AI 助手**：分别配置文字与生图服务，获取画面建议、生成配图、润色文稿或检查发布风险，并保存常用风格。
- **多种导出**：一键导出 Word，或选择 Markdown 双栏表格、分段正文、源码预览与复制；JSON 用于完整备份和恢复。
- **手机与字号适配**：窄屏自动切换段落卡片，制作说明可折叠；“显示设置”可将界面、正文和弹窗字号统一调整为 90%–150%。

## 开始使用

### 在电脑上启动

1. 安装 Node.js 22.13 或更新版本，下载本仓库并解压。
2. Windows 双击 **启动幕稿.cmd**。首次运行会自动安装依赖，等待窗口显示启动成功。
3. 在浏览器打开 **http://localhost:3000/**，运行期间保持启动窗口打开。

其他系统或希望手动启动时，在项目目录运行：

```sh
npm ci
npm run dev
```

关闭启动窗口后服务会停止，已经保存的稿件仍留在浏览器中。请固定使用同一个网址；`localhost`、`127.0.0.1`、不同端口和不同浏览器分别保存各自的稿件。

### 写一份脚本

1. 从侧栏选择 **新建脚本**，填写标题和简介；已有文案可用 **导入文案 / 备份** 粘贴，按空行拆成段落。
2. 逐段填写文案、画面、BGM 和附注。用段落菜单或六点拖拽柄整理顺序，大纲可快速跳转。
3. 根据口播统计调整语速和停顿。需要固定镜头长度时，为该段设置手动时长；它会替代自动估时。
4. 等顶部显示 **已保存到本机**，再导出交付文件或下载 JSON 备份。

字数只统计文案中的文字和数字，不含标点、空白、表情、标题和制作说明。默认按中文 240 字/分钟、英文 150 词/分钟估时；标点不会自动增加停顿，实际口播请以试读为准。

### 手机操作

在手机浏览器打开已部署的幕稿网页，左上角菜单可切换脚本或查看大纲。每段先显示文案，下方的 **画面与制作说明** 可展开或收起。

长按段落或大纲中的六点柄约半秒，看到“拖拽中”后上下移动并松手完成排序。绿色横线表示插入位置，拖到边缘时会自动滚动；也可以使用段落右上角的 **…** 菜单。

电脑上的 `localhost:3000` 仅供该电脑访问，不能直接作为手机地址。电脑和手机的稿件分别保存，换设备时通过 JSON 导出、导入转移。

## 配图与 AI 助手

### 添加段落配图

每段支持一张 PNG、JPEG 或 WebP 图片，单张不超过 20 MB。添加后可替换、移除或放大查看，图片会随稿件和 JSON 备份保存。

复制和移动段落会保留配图；分段后图片留在前半段。两段各有不同配图时，需要先移除一张再合并，以免丢图。Word 和 Markdown 仅导出文字。

### 配置服务

1. 打开侧栏的 **AI 设置**，分别填写文字、生图服务的基础地址、模型名称和 API Key。两种服务可以使用不同的供应商。
2. 基础地址通常形如 `https://api.example.com/v1`，不要填写具体功能接口的路径；本机服务可使用 `http://localhost:端口/v1`。公网服务需使用 HTTPS，并允许浏览器从幕稿网页直接连接（CORS）。
3. 可点击 **测试文字连接**，成功后保存设置。画面建议、润色和审查还需要文字模型支持 JSON 输出模式，连接测试本身不检查这项能力。
4. 按需保存 **画面风格**、**文稿风格** 和常用审查平台，之后的任务会自动带入，也可为单次请求补充要求。

生图支持 OpenAI 兼容服务和硅基流动。尺寸可留空采用默认值，或填写服务商支持的尺寸；硅基流动 Kolors 留空时使用 `1024x1024`。模型名称、可用尺寸和费用以服务商为准。

### 使用 AI

| 功能 | 使用方式 |
| --- | --- |
| 画面建议 | 从段落制作说明上方进入，查看并编辑建议后追加或替换画面与附注。 |
| 生成配图 | 先填写画面或附注，再请求一张图片。生成成功后自动放入对应段落，可撤销。 |
| 润色文稿 | 从工具栏的 AI 助手选择整稿或单段，对照原文后应用，制作说明和时长保留。 |
| 合规审查 | 选择平台后查看风险原文、修改建议和依据，可定位对应段落，稿件不会自动修改。 |

返回格式不正确时，原稿保持不变，可以重试或更换模型。生成期间稿件被修改、删除或切换后，会阻止应用过期结果。远程图片下载失败时，可能暂时保存服务商链接；请下载图片后手动添加，避免链接过期。

内置平台资料是 **2026-10-05 整理的有限摘要**，覆盖抖音、小红书和 B站的部分公开规则；视频号官方正文未能核验，默认仅提供通用风险提示。可在设置中补充最新规则并注明平台、来源和日期。审查只分析提供的文字，不能核验图片内容、素材授权或账号资质，也不保证平台过审。

### 稿件与密钥

普通编辑和导出在本机完成。只有主动生成、审查或测试连接时，才会将相应内容发送到配置的服务，调用前会显示接收服务和处理范围。

API Key 默认仅保存在当前标签页，刷新保留、关闭后清除。勾选 **记住 API Key** 会将密钥明文保存在浏览器的网站数据中，请只在可信设备使用；可随时清除。密钥和 AI 设置不会进入稿件、导出文件或历史版本。

AI 调用及连接测试可能产生服务商费用。HTTP 402 通常表示余额不足或欠费，请检查服务商账户；取消或超时只停止浏览器等待，服务商仍可能继续处理并计费。长文可逐段处理，单次文字请求内容上限 60,000 字符，生图提示词上限 16,000 字符。

## 导出、备份与恢复

| 格式 | 适合用途 | 恢复方式 |
| --- | --- | --- |
| Word `.docx` | 交付、审稿、打印；A4 表格包含段号、文案和制作说明。 | 暂不支持 Word 导入。 |
| Markdown 双栏表格 | 在支持表格的 Markdown 工具中对照文案和制作说明。 | 暂不支持直接还原为完整脚本。 |
| Markdown 分段正文 | 长文阅读、复制或继续写作。 | 可粘贴正文，按空行重新分段。 |
| JSON | 转移单份稿件或备份全部脚本，保留制作说明、配图、顺序、语速和时长。 | 导入后创建副本，不覆盖现有脚本。 |

导出当前稿件：右上角 **导出 Word**，或从 **更多导出格式** 选择 Markdown、预览 / 复制源码、**导出当前脚本 JSON**。

备份全部稿件：点击侧栏的 **备份全部脚本**，或在导出菜单选择 **JSON 备份全部脚本**。恢复时打开 **导入文案 / 备份**，选择 **恢复幕稿 JSON 备份**。

历史版本会在编辑期间每分钟保留一份旧版本，最多十份，通过 **恢复副本** 找回；撤销与重做最多保留 80 步，关闭页面后清除。

## 数据保存须知

- 稿件只保存在 **当前浏览器、当前网址**，没有账号登录、云同步或多人协作。
- 清理网站数据、删除浏览器配置或关闭无痕窗口，可能丢失稿件。请定期把 JSON 备份下载到自己的文件夹，本机历史不能替代独立备份。
- 以 **已保存到本机** 提示为准。保存失败时先导出当前稿件；两个标签页发生版本冲突时，先下载备份再载入最新版本。
- 每份脚本最多 500 段，本机最多 100 份，单栏最多 50,000 字符，JSON 导入最多 128 MB。含图片的大稿件可能需要更长的保存和导出时间。
