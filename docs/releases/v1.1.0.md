# 幕稿 v1.1.0

这一版加入可配置 AI 助手与段落配图，并完善手机操作和 API 设置保存。

- **AI 助手**：文字和生图服务可分别配置，支持画面建议、文稿润色、生成配图和发布风险审查；可保存常用风格，查看结果后再应用文字修改。
- **默认记住 API 配置**：地址、模型和 Key 保存后可跨标签页、跨浏览器重启继续使用，也可手动改为仅当前标签页保留 Key。
- **段落配图**：上传、预览、替换或移除图片，配图随段落一起移动，并可通过 JSON 备份恢复。
- **编辑体验**：完善手机段落拖动、制作说明布局和导出操作；显示设置可统一调整界面、正文及弹窗字号。
- **使用说明与项目目录**：README 侧重功能和用法，源码集中在 `src/`，附目录导览。

## 下载和使用

- `mugao-v1.1.0-web.zip`：已编译的静态网页，将其中的 `mugao/` 放到网站根目录，以 `/mugao/` 访问。解压后可阅读 `STATIC_PACKAGE.md`。
- `SHA256SUMS.txt`：静态网页包的 SHA-256 校验值。
- GitHub 的 **Source code**：完整源码，按 README 启动。

在线使用：[幕稿](https://wuzhiya.top/mugao/)。在线站点的更新由站点部署单独完成。

升级后在 **AI 设置** 中保存一次即可启用默认记住；旧版已经清空的 Key 需要重新填写。继续使用原浏览器和原网址即可读取已有稿件，也可先导出 JSON 备份。
