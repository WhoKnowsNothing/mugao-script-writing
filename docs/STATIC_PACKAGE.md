# 幕稿静态网页包

静态网页 ZIP 已完成编译，包含 `mugao/` 目录、此说明和 MIT 许可证。

## 部署到网站

1. 解压 ZIP，把完整的 `mugao/` 目录放入网站根目录，保留 `assets/` 等子目录。
2. 通过 `https://你的域名/mugao/` 打开。此发布包固定使用 `/mugao/` 路径。
3. 配置 AI 时，服务商需要允许该网站的浏览器跨域请求。稿件仍保存在访问者的浏览器里。

这是静态网页，无需应用数据库或专用后端。升级时替换完整的 `mugao/` 目录并刷新页面。

## 在本机预览

如果已安装 Python，可在解压目录运行：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8080/mugao/`。也可以使用其他静态网页服务器；直接双击 `index.html` 无法正确加载此包。

请固定使用同一个浏览器和网址。更换域名、端口或浏览器时，通过 JSON 导出、导入转移稿件。升级前可先导出一份 JSON 备份。

旧版本升级后，在 **AI 设置** 中保存一次，即可按新的默认选项记住地址、模型和 Key。已被旧版清除的 Key 需要重新填写。
